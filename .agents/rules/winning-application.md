# Rule: Winning Application Standards

This rule enforces the technical, design, and strategic checklist across all files and components:

1. **Frontend**:
   - Ensure all React components are modular, typed, and resilient.
   - Guard every view with high-quality loading, empty, and error states.
   - Use design system tokens for spacing, typography, colors, and shadows.

2. **Backend**:
   - High-throughput asynchronous routing and processing.
   - Transparent schema validation and end-to-end data flow mapping.

3. **Machine Learning & Processing**:
   - Safe model weight lifecycles (startup pre-warming, `inference_mode`).
   - Stream live data and audio signals asynchronously without blocking the UI thread.

4. **Strategy & Presentation**:
   - First-principles clarity for every feature addition.
   - Crisp technical narrative and interactive showcase components.
